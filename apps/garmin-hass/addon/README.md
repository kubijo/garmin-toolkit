# Garmin Toolkit for Home Assistant

Import a GPX route, generate a Garmin FIT Course, and download both through Home Assistant ingress.

This app is experimental. Keep a backup before updating. Only install a release that lists your Home Assistant
architecture as supported. Physical USB transfer support depends on the device, firmware, and host; a successful app
installation does not establish device compatibility.

See [DOCS.md](DOCS.md) for installation, the first route workflow, backups, removal, and troubleshooting. Changes are
listed in [CHANGELOG.md](CHANGELOG.md).

Source, release assets, checksums, and verification instructions are available from the
[Garmin Toolkit project](https://github.com/kubijo/garmin-toolkit).
