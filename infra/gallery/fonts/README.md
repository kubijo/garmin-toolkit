# Bundled gallery fonts

`DepartureMono-Regular.otf` is the unmodified Departure Mono 1.500 release by Helena Zhang. The gallery bundles it as
the deliberately pixel-styled comparison face; it is not part of the shipped `garmin-cli` binary.
